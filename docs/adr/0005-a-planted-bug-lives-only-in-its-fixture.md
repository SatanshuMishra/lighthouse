# A held-out fixture's planted bug is written only inside its fixture folder

The first held-out set was retired because a decisions line every Worker read named each fixture's planted bug, so the skills were written by authors who knew the cases they are judged on. A planted bug is now written only under tests/fixtures/held-out, never in a spec, decisions file, record, task, glossary entry, decision record or commit message; each fixture's author chooses its bug alone, and a probe beside the fixture proves the bug is real without anyone describing it elsewhere.
