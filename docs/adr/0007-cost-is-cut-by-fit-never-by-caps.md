# Cost is cut by fitting checks and removing waste, never by caps

Status: accepted

lighthouse serves a pipeline that can build anything, so no limit on project size, change width, paths, surfaces, files, trials or time is ever used to make a run cheaper or faster. Savings come from removing time and tokens that buy no proof (repeated suites, blind waits, re-read context, expired caches) and from giving each product path the lightest check that still observes its expected outcome, recorded with why it fits; a run never narrows its scope to save time, and what it cannot reach is unproven.
